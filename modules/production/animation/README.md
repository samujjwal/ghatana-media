# 2D animation renderer

`AnimationRenderer` accepts the existing versioned `AnimationSpec` envelope plus a separately resolved, closed Java scene value. The PDP-1 envelope intentionally carries opaque version references; the owner has not asserted a field mapping from those references to scene objects. This module therefore makes no implicit graph lookup, asset fetch, or rights decision. Its first implementation profile explicitly supports pixel-space rectangles, ellipses, and lines with frame-index transform keyframes, four easing functions, and PNG output.

The renderer uses only the JDK 2D and PNG APIs. It executes no user code, expression, shader, or asset decoder. Coordinates and dimensions are pixels; keyframe translation is pixel-relative; scale is a nonnegative ratio; rotation is degrees; opacity is in `[0,1]`. Supported primitives are rectangles, ellipses, lines, and seeded procedural particle fields. Frame PTS is an exact rational number of seconds. Each frame also records the exact rational story-clock tick value derived from the envelope's initial tick and rational time base; overflow beyond the canonical signed-int64 tick domain is rejected. This is a local rendering assumption and does not establish a canonical PDP graph mapping or an approved external codec.

Inputs are bounded before rendering: 2048 by 2048 per frame, 240 frames, 33,554,432 total raster pixels, 4096 vector shapes, 64 particle fields, 10,000 particles per field, 1,000,000 particle draws per animation, 240 keyframes per shape, 16 MiB per encoded frame, and 64 MiB aggregate PNG output. The JDK PNG writer produces real decodable pixels; this module does not produce video, audio sync, 3D, text/math layout, accessibility shadows, asset resolution, or qualified production media. Pixel identity is verified on the test host/JDK; no cross-platform codec or renderer qualification is claimed.
