## A. Binding engineering decisions — what is now decided

1. **First complete outcome is real source-version-bound STT, not 36 parallel test additions.** After one source-owned, consent/purpose-verified model input produces a real transcript, persist through the canonical Media artifact, job, attempt fence, outbox and Postgres revision, re-read after restart, and prove no duplicate effect after ambiguous response. Only then review STT-03/04/08/09 for full original-row acceptance. No `ADMITTED` flag, environment setting, issuer label, or synthetic text is evidence by itself.
2. **Reference STT:** use the official *multilingual* Whisper `tiny.pt` (PyTorch) with the published SHA-256 `65147644a518d12f04e32d6f3b26facc3f8dd46e5390956a9424a650c0ce22b9`, the exact source-pinned tokenizer, and a separately pinned and tested *compatible ONNX export*. A `.pt` file is NOT loadable as ONNX. Verify frontend mel shape, decoder/autoregression, BPE, start/end/language tokens, and real nonempty text against the original implementation. Export recipe and ONNX bytes get their **own** hash and rights review; never rename a `.pt` file to `.onnx` or assume fused encoder output.
3. **Reference TTS:** choose Piper **`en_US-ljspeech-medium`** (not Lessac or Ryan). Its source MODEL_CARD states trained from scratch on public-domain LJSpeech; the Hugging Face model page reports ONNX SHA-256 `6f52a751e2349abe7a76735eb09dc1875298c77ea2342ffd2fef79ff81b87f22`. Independently pin repository commit and `.onnx.json` digest, verify espeak-ng phoneme symbols and output PCM against real decoded speech, and document speaker/likeness rights. Repo-wide `MIT` alone cannot resolve the latter. Lessac Blizzard 2013 data explicitly restricts commercial use; do not select a Lessac-derived voice for an unconditional commercial reference. **No clone/identity rights are inferred from using a generic TTS voice.**
4. **Reference detector:** choose official Megvii **YOLOX-Nano ONNX** at release `0.1.1rc0`, `yolox_nano.onnx` (3,659,407 published bytes), with Apache-2.0 *source* license and separately reviewed weight/training lineage. Its input/output contract is `[1,3,416,416]` → `[1,3549,85]`, incompatible with Media's current YOLOv8 `[1,84,N]` parser. Implement and test a separate YOLOX-specific preprocessing/output/anchor decode adapter under **Media Vision**, preserving YOLOv8 for independently qualified profiles only. Pin independent onnx SHA after fetching; current catalog intentionally has `null`, which blocks positive intake until the digest is reconciled. Do not silently repurpose an AGPL/Enterprise YOLOv8 model as Apache-2.
5. **ASR corpus:** Google FLEURS source revision `70bb2e84b976b7e960aa89f1c648e09c59f894dd`, CC-BY-4.0, exact language configs **`eng`, `hin`, `npi`**. First evaluation pack: up to 24 independently hashed, labeled clips **per locale**, each ≤30 s, deterministic stable manifest of source row/split, text/transcript, audio SHA, clip licence/attribution, source revision, and evaluation-only scope. Reserve a disjoint holdout before running Whisper. Download **only selected rows**, not the entire dataset. Record per-locale WER/CER, noise/accent/failure and missing-language disposition. No benchmark numbers are assumed before execution.
6. **Human speaker/face/voice rights:** separate *functional ASR and public-dataset evaluation* from *human likeness/biometric processing*. For voice cloning, speaker identity, face matching and consent-revocation cases, use an original, paid/volunteer **adult participant** with an individually signed and independently reviewed opt-in specifying exact recording, use/processing/region/retention, training vs inference, embedding retention, voice clone vs face identity as **separate defaults-off purposes**, third-party egress, withdrawal/deletion and contact. A general recording release does **not** authorize cloning or biometrics. Store signed documents, recordings, names, keys and identity bindings in a restricted private rights store; commit only redacted reference/digest/status metadata. Source consent must be rechecked through MediaConsentAuthority and Shared trusted policy **at every dispatch/retry**, and revoked sources cannot be replayed.
7. **Nonhuman source rights:** use entirely original deterministic FFmpeg test clips/screen flows with generator source SHA/seed, audio/image samples and exact owner declaration for codec, clock and API tests. For a real product demo, document ownership or explicit processing/derivative/distribution grant from the actual screen, media/music, narrator, font and included content owners for the exact scenario and purpose. Never infer recording rights from upload authentication or a software license.
8. **Vision/cross-modal corpus:** initial timing correctness uses generated flashes+tone impulses and VFR timestamps, recorded source origin/timebase/epoch/digest, positive/negative offsets and missing-discontinuity cases. Real object-detection mAP must use an **independently licensed labeled image corpus**, with original image-level photographer/source/license/attribution; COCO annotation licensing alone is not blanket image redistribution rights. Biometric speaker-to-face accuracy requires separate consented recordings; otherwise those operations remain `NOT_ADMITTED` and cannot be counted as a real-positive acceptance.
9. **Provider quality & load:** test the **actual model on the named Mac ARM64 and Linux ARM64 (Docker on Mac)** with exact CPU, RAM, image, JDK, codec, quantization, model hashes, data hashes and no hidden fallback. Execute 1/16/64 simultaneous request scenarios using bounded queues and time budgets. Report admitted/completed/rejected/timeout/UNKNOWN counts, p50/p95/p99, RTF/frames/s, peak RSS/native memory, CPU, disk, threads, network and model load cold/warm. A 64-request overload can validly reject with bounded typed errors; do not fake 64 successes. GPU measures are `NOT_APPLICABLE` only for a deliberately approved CPU-only profile, not presumed zero.
10. **Worker isolation:** one CPU/RAM/PID/temp/time-bounded Linux ARM64 worker per untrusted native media operation, on Docker Desktop for Mac and Linux on native host. Enforce container cgroup/resource limits on **that worker**, not just a shared Gradle test-container. Prove forced OOM, PID/fork explosion, timeout, cancellation, and output/diagnostic/temp byte caps; no result, orphan process or unbounded log survives. Unsupported host → fail closed. Do not equate sampled RSS with a hard memory limit.
11. **No duplicate cross-repo APIs:** Ghatana [#254](https://github.com/samujjwal/ghatana/issues/254) owns Data Cloud versioned Media observation read-model transport and Java21↔27 interoperability; Ghatana [#252](https://github.com/samujjwal/ghatana/issues/252) owns Document Intelligence source/ROI/rights OCR client/worker boundary. The public transport must enforce source version, principal, purpose, consent, idempotency, UNKNOWN/readback. Neither is a prerequisite for independently completing the first direct STT runtime job. Do not move Ghatana internal DTOs or generic OCR into Media.
12. **Evidence cannot self-admit.** The catalog is source reconnaissance, not authorization. Packet file hash verification is not a rights decision. Detached Ed25519 receipts must be from *pre-registered trusted public keys with specific allowed review scopes*, not a public key supplied in the same packet. The Media intake checker returns `INTEGRITY_CHECKED_INDEPENDENT_OWNER_REVIEW_REQUIRED` even with verified signatures; only the existing Shared PolicyEngine and Media Consent/rights authority can grant actual runtime effects. The checked-in trust-anchor list starts **empty**; that is truthful until externally authorized reviewers are registered.

A candidate packet's `artifacts` enumerate local files, role, relative path and SHA-256. Its signed receipts are external reviewer attestations over exact subject/model hash, permitted purpose, scope, and time. The public-key verifier is pinned in the repository, not supplied by the packet. Only an independent authority can bind a reviewed rights grant to a particular artifact and current consent. An integrity-verified packet returns **`INTEGRITY_CHECKED_INDEPENDENT_OWNER_REVIEW_REQUIRED`**, not `ADMITTED`; only Media's existing trusted runtime authority can admit an operation at dispatch time. An unknown upstream digest stays blocked until an independent source pin is obtained.

## G. Source-pinned reference asset staging (implemented R9 extension)

It uses HTTPS host and redirect allowlists, bounded downloads, a timeout, owner-only off-repository storage, exact digest verification, no overwrites, and atomic publication after verification. No runtime, test or launcher implicitly downloads weights. `SOURCE-RECEIPT.json` proves content bytes alone and is explicitly **not license, consent, model-compatibility, quality or production admission**.

FLEURS is sampled by *clip*, not as one bulk model file, and the chosen clip/gold/attribution manifests must be separately reviewed.

The local test design includes **5** reference-staging cases and **9** signed-evidence/source-crosswalk cases.
