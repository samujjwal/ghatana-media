test-only). Cross-language vector `runtime-contracts/src/test/resources/scan-attestation/ed25519-interop-v1.json` is generated by

## Runtime port: principal-scoped job cancel (Kernel media-stt adapter request)
`MediaProcessingRuntimePort.cancelJob(tenantId, principalId, jobId)` returns `JobCancellation(outcome, job)` with `CancelOutcome`
CANCELLED (reported only when the stored job status is CANCELLED), ALREADY_TERMINAL (COMPLETED/FAILED, nothing cancelled), UNKNOWN
(cancel requested/unsupported, job not CANCELLED) and NOT_FOUND (unknown job, or wrong tenant/principal - indistinguishable). Default
implementation fails closed (NOT_ADMITTED); `MediaRuntime` implements it over the existing owner-scoped `cancelOwnedJob`.
