### F5 — Aggregate project/history resource budget is not defined

- **Path-scoped tests:** `ProjectTimelineRevisionModelTest` and `ProjectTimelineEngineTest` boundary cases; PostgreSQL canonical/development store exact-bound, rollback, restart, and concurrent-CAS tests; launcher rejection/readback test; a reproducible benchmark at each approved bound.

- **Evidence Generator enhancement required:** F4's `EG-TIMELINE-001` must collect budget/retention source identity, limit tests and measured resource artifacts; no local default can satisfy an absent owner budget.
- **Classification / convergence impact:** Production admission prerequisite blocked on owner-defined limits. Do not claim unbounded history as production-safe; current DEV_ONLY usage stays scoped and clearly documented.
