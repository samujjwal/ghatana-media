# Rights-Aware Cache — Mandatory Surface Closure Matrix (2026-11-10)

## Scope and decision

Scope: `modules/infrastructure/cache/**` cache adapter and its consumers. Plan source: `media.dev.rights-aware-cache` in `docs/development/remaining-work.json`. Owning build unit: `:services:media:modules:infrastructure:cache`; focused integration unit: `:services:media:modules:infrastructure:cache:integrationTest`.

Review disposition: `not-converged-actionable`. Existing local code correctly partitions protected keys by tenant, principal, rights, purpose, classification, source/transcript identities, policy epoch, model-license reference, and revocation epoch; typed current authority is time-bounded and rechecked around lookup and disclosure. The local loader now returns a typed snapshot and the adapter checks the complete observed scope before insertion. That contract depends on a truthful host loader: the public SPI cannot cryptographically prove that a caller did not echo the requested scope, and no production runtime caller or owner-backed provider is wired. Replayable invalidation events are also absent. These integrations must not be invented in this adapter.

## Findings

### CACHE-01 — protected source snapshot scope binding (implemented locally)

- Priority: P1; area: correctness/security; classification: current-state gap.
- Where: `modules/infrastructure/cache/src/main/java/com/ghatana/audio/video/infrastructure/cache/TranscriptionCacheService.java`, `loadScopedEnvelope` and `isValidEnvelope`.
- Problem/root cause: the old scoped loader accepted only a transcription UUID and returned an entity, so the adapter could not detect a source result whose immutable identity differed from its requested key.
- Production-ready fix: `ScopedTranscriptionLoader` now returns a `ScopedTranscriptionSnapshot` with an observed scope and transcript ID; exact equality is checked before cache insertion. Format-2 envelopes preserve only the derived key digest and transcript ID, not raw scope values. The host loader still must derive observed scope from independently fetched source and authority facts; the SPI cannot prove provenance.
- Acceptance criteria: exact snapshot succeeds; every scope-field mismatch, transcript-ID mismatch, or missing persisted version fails without cache put/disclosure; deleted/absent results are not cached; stale v1 envelopes refresh under current authority.
- Path-scoped tests: `TranscriptionCacheServiceTest` exact match, all 12 scope dimensions, transcript identity, missing version, deletion, format-v1 refresh, no-write, and current-authority checks.
- Path-scoped evidence: FULL DEV_SOURCE_COMPOSITE cache unit suite PASS 124/124 (zero skips/failures/errors); Redis integration suite PASS 11/11 (zero skips/failures/errors); `pnpm check:surface-docs` PASS 59 READMEs/577 cited types; `git diff --check` PASS.
- Evidence Generator enhancement: none for this local bug; tests provide focused engineering evidence. No convergence score is claimed.
- Convergence impact: local entity-to-scope mismatch is closed under the documented trusted-host callback boundary. Production correctness remains unproven until an owner-backed loader/provider uses independently read scope facts.

### CACHE-02 — runtime owner authority and replayable rights invalidation are not wired

- Priority: P1; areas: feature completeness, privacy, reliability; classification: current integration gap with owner/platform contract dependency.
- Where: no protected cache caller found under `modules/`, `adapters/`, or `launcher/`; lifecycle contract has no rights/consent/retention cache-invalidation event identity/readback.
- Problem/root cause: a cache SPI cannot manufacture authenticated principal, consent/retention state, policy epoch, revocation epoch, or replayable invalidation identity.
- Production-ready fix: wire an actual source-backed runtime consumer to the current owner authority and consume an owner-defined replayable invalidation/readback contract. Preserve source-only behavior until both are available.
- Acceptance criteria: real caller builds scope from verified immutable source and current owner evidence; revoked/expired scope cannot disclose after restart; event loss/replay converges exact invalidation without tenant-wide accidental deletion; duplicate event is idempotent.
- Path-scoped tests: launcher/provider integration with durable source rights, policy authority, Redis restart, invalidation replay, and no-authority/unknown cases.
- Path-scoped evidence: no artifact can establish this until the owner contract and runtime composition exist.
- Evidence Generator enhancement: after contract admission, add an integration collector for source-rights decision, event cursor/replay, exact key identity, and post-restart cache outcome.
- Convergence impact: production cache admission remains open; no current runtime caching is claimed.

## Final closure decision

`not-converged-actionable`. The typed local source-scope boundary and its adverse tests are implemented. The callback provenance cannot be established by this infrastructure module, and no production caller, owner-backed cache authority composition, or replayable invalidation identity is present. Keep `media.dev.rights-aware-cache` OPEN and do not invent those external semantics.
